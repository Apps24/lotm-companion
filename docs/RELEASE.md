# Book 1 companion release

Release target: Cloudflare Pages (`https://lotm-companion.pages.dev`).

The final Phase 7 release contains:
- 1,430 canonical numbered chapter routes and title metadata
- curated Chapter 2 companion notes
- Klein progression graph
- Tarot Club progression and interaction layer
- important Book 1 world entities and all 22 standard pathways
- spoiler-gated timeline/search
- 328-record EPUB visual metadata catalogue and project-generated visual gallery
- shared navigation and spoiler persistence
- source/copyright policy, canonical validation and static release QA

No source chapter prose is committed. EPUB image bytes remain excluded unless they are project-generated assets with publishable provenance.
