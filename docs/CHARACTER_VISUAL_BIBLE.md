# Character visual consistency bible

Reference roster: Klein, Audrey, Alger, Derrick, Fors, Emlyn, Cattleya, Leonard, Xio, Azik, Amon, Adam, Roselle, Bernadette, Reinette, Sharron and Dunn.

For every new generated scene, lock facial structure, apparent age, hair silhouette, recurring outfit language and signature props to the project reference for that character. Do not infer an unrevealed transformation from later knowledge. The artwork record must carry the chapter it depicts and a `spoilerChapter`; later Sequence forms, aliases and items cannot appear earlier.

Visual direction: realistic dark Victorian fantasy; late-industrial / steampunk Loen; restrained occult symbolism; volumetric fog; antique brass, dark wood and gray stone; crimson prayer stars in Sefirah scenes. Avoid modern fantasy armor unless the source chapter supports it.

Appearance-specific details are source-controlled: confirm them against the supplied EPUB or an already-approved project image before generating a new scene. The data file `data/visuals/character-bible.json` carries the same rule per reference character.
