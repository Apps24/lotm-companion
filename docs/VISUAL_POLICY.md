# Visual provenance policy

The public companion distinguishes three visual classes:

1. **EPUB embedded art** — catalogued with filename, dimensions, source document and chapter references. The original bytes are not republished by default because possession inside the user-supplied EPUB does not establish redistribution rights.
2. **Project-generated AI visualization** — may be stored and displayed when generated for this project. Every record is labelled `ai-visualization`, includes a spoiler chapter, and names its provenance.
3. **External fanart** — never copied or hotlinked blindly. A future record must include artist, canonical source URL, platform, permission/licence status, spoiler chapter, and whether a local copy is permitted. If those fields are unavailable, the artwork must not be republished.

Visual direction follows the project bible: realistic dark Victorian fantasy, late-industrial Loen, restrained occult symbolism, cosmic horror, volumetric fog, antique brass, dark wood and gray stone. Character designs should remain consistent across generated scenes.
